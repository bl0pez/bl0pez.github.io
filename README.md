# Portafolio de Bryan López

Sitio de presentación: webs, apps y automatizaciones con n8n para negocios en Chile.

- Hecho con [Astro](https://astro.build), sin JavaScript en el cliente.
- Se publica en https://blopezdev.com (GitHub Pages) con cada push a `main` (`.github/workflows/deploy.yml`).

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Contexto de diseño

- `PRODUCT.md`: a quién le habla el sitio, qué se puede publicar y qué no.
- `.impeccable/surfaces/`: dirección de diseño de la portada.
- Skills usadas: impeccable, hallmark, emil-design-eng y design-taste-frontend (listadas en `skills-lock.json`).
